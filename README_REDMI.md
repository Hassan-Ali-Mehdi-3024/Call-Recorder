## 🔋 IMPORTANT: BATTERY SETTINGS

MIUI is aggressive with battery management. Do this once:

```
Settings → Apps → Manage Apps → Call Recorder
→ Battery saver → "No restrictions"
→ Autostart → Enable
→ Display pop-up windows → Enable
```

**This ensures the app keeps running to catch all calls!**

---

## 📂 WHERE ARE MY RECORDINGS?

**Location**: 
```
Android/data/com.callrecorder/files/CallRecordings/
```

**Filename format**:
```
Call_<PhoneNumber>_<Date>_<Time>.3gp
```

**View in app**: All recordings show up in the list with date/time
